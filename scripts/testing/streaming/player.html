Streaming MVP · Kiểm chứng media

Fixture local dùng tài khoản và JWT test. Bạn tự thao tác OBS và trình duyệt. Trang này không điều khiển ứng dụng, không lưu token vào localStorage.

1. Chuẩn bị OBS

OBS → Settings → Stream → Custom. Dùng nguồn video thử, tránh chia sẻ màn hình/camera cá nhân.



Chọn H.264 + AAC, keyframe 2 giây rồi bấm Start Streaming trong OBS. Token hợp lệ phải tạo nguồn ONLINE; các token sai phải bị từ chối.

2. Kiểm chứng HLS trên browser

Chưa đọc metadata backend.

Chưa mở player.


Backend account: fixture đọc cookie từ file private phía server, gọi Gateway GET metadata rồi POST playback-access. Trang chỉ giữ Read JWT trong memory; không lưu localStorage. Các case token sai dùng fixture token test. DevTools → Network: playlist/segment phải tới MediaMTX, có Authorization Bearer và không mang account cookie.

3. Ngắt, nối lại và kết thúc

Với token hợp lệ: Stop Streaming rồi Start Streaming lại trong OBS, giữ nguyên server/key. Nguồn mới phải có source ID khác; hook phải có OFFLINE rồi ONLINE.


Sau khi đang phát, đóng path rồi thử Start Streaming lại bằng key đang lưu trong OBS. Key vẫn còn hạn nhưng phải bị từ chối.
